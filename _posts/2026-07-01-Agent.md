# For Agent: The Meaning of Life

> "I may venture to affirm of mankind, that they are much oftener led by their hearts than by their understandings." 
> — David Hume

如果把人简单粗暴地理解为由欲望驱使的生物，那么人的行动并不总是由纯粹理性支配。这里的“欲望”不只是食色性等浅层的 corporeal passion，也包括更复杂的社会性欲望：被认可的欲望、服从规训的欲望、追求成功的欲望、行善的欲望，甚至是成为“一个好人”的欲望。换言之，人并不是先拥有一个完全清晰的理性目标，然后再冷静地选择路径；更多时候，是欲望先为世界赋值，理性再为这些赋值寻找解释、路径和正当性。

把 Agent 类比为人时需要先澄清一点：strictly speaking, agent \(\neq\) human；在 reinforcement learning 中，agent 首先是一个数学抽象，即一个在状态下选择动作、并能根据经验改变选择方式的决策系统。它的行为方式由 policy 描述：
$$\pi(a|s)=Pr(A_t=a|S_t=s)$$即当 agent 处于状态 \(s\) 时选择动作 \(a\) 的概率。因此，policy 可以被粗略类比为人的行为习惯或行动倾向：在某种处境中，一个人“倾向于”如何反应。与此相对，reward function 则规定了什么对 agent 来说是有价值的：$$r(s,a)=\mathbb{E}[R_{t+1}|S_t=s,A_t=a]$$，即在状态 \(s\) 下采取动作 \(a\) 后可以期待得到的即时 reward。人的欲望结构可以被松散地类比为 agent 的 reward function，因为欲望同样为世界赋值，使某些状态值得追求，某些状态值得避免。但 agent 并不只是追求下一刻的 reward；它追求的是长期的 expected return，即
$$G_t=\sum_{k=0}^{\infty}\gamma^kR_{t+k+1}$$ 的期望值。因此，对于一个 RL agent 来说，所谓“意义”可以被形式化为在给定 reward structure 下寻找最优 policy：$$\pi^*=\arg\max_\pi \mathbb{E}_\pi[G_t]$$换言之，agent 的 meaning of life 不是某种内在灵魂或先验使命，而是在 agent-environment loop 中不断选择行动、接受反馈、并调整自身，以最大化长期 expected return。这个类比的危险也正在这里：human desire 并不像 reward function 那样干净、单一、可计算；人的欲望往往由身体、社会规训、他人目光、创伤和历史共同塑造。因此，agent 的问题是如何最大化 reward，而人的问题则更进一步：我正在最大化的究竟是哪一种 reward？这套 reward function 又是谁写进我的？
